# Tile artwork: source, fallback, and rendering

1. Resolve icons using the installed loader against the active JSON before changing files. Check whether an explicit relative `icon` names a missing legacy PNG: replacing an example or adding an SVG alone will not fix an older config unless the loader resolves to it. Preserve an existing custom icon; for a missing icon, prefer a local match by item ID, then the bundled streaming SVG in `config/icons/`. Treat branded and generic folder artwork under `qml/assets/` as UI assets, not config-relative files. For Steam game tiles, check the client’s `appcache/librarycache/<appid>/logo.png` before searching elsewhere. Copy verified artwork to the active config’s `icons/<tile-id>.png` without replacing custom art, then resolve it with the installed `load_config` and `find_item`; the AppID selects the Steam cache entry, while the tile ID selects the Media Hub icon.
2. Use recognizable brand vectors from upstream and credit each asset. An official website may use an SVG `<symbol>` sprite rather than a standalone logo (SVT Play does); extract the appropriate symbol with its `viewBox`, wrap it in a standalone SVG, and check that it has no scripts or external references. Keep a small folder badge on subcategory tiles regardless of the main artwork; use the generic folder as the main icon only when there is no dedicated artwork. Steam’s bundled subcategory artwork comes from the client’s `controller_base/images/api/knockout/sc_button_steam.svg` (the symbol, not the `sd_button_steam.svg` button label). Verify the `steam` branch of the QML folder model and keep the generic fallback covered by navigation tests. Prefer a light-on-dark brand variant; if adapting colors, preserve the shape and document the change.
3. If there is no usable vector, try the official site’s `apple-touch-icon` and decode the downloaded bytes with `QImage` before installing them—a `.png` URL can return HTML. Create the config-relative `icons/` directory if absent. To round a single square bitmap, back up that asset and apply an antialiased circular alpha mask with `QPainter.CompositionMode_DestinationIn` on `QImage.Format_ARGB32_Premultiplied`; save as PNG and replace atomically. Verify transparent corners and nontransparent center on readback. Do not change the shared tile component for a one-icon request.
4. For sharp SVGs in Qt Quick, set `Image.sourceSize.width` from the displayed icon width at about 2× (`Math.ceil(width * 2)`), preserving aspect ratio and leaving bitmap sizing alone. Set this for SVG app tiles as well as folder tiles: Qt otherwise can rasterize a vector at its small intrinsic dimensions and then upscale the bitmap. Test the actual QML image's source size, not just whether `QImage` can decode the SVG.
5. Verify the installed result at TV resolution using a fresh isolated launch. For the default streaming view use no playback keys: from the installed prefix, run `QT_QPA_PLATFORM=offscreen QT_QUICK_BACKEND=software .venv/bin/python -m mediahub --windowed --size 1920x1080 --no-log-file --screenshot "$TMPDIR/media-hub-streaming.png" --screenshot-delay 1000` with physical controller input excluded. Inspect the screenshot at normal scale for contrast and sharpness on the actual dark card; a successful decode does not prove readability. Check folder views using the isolated navigation harness described in SKILL.md. Import `QQuickWindow` from `PySide6.QtQuick` before loading QML when inspecting `rootObjects()[0].contentItem()` or capturing `grabWindow()`; registering the wrapper prevents a generic `QWindow` object from hiding those methods. Assert the intended section and the actual tile image before capturing it.
